## 摘要
深度联合信源信道编码（Deep JSCC）通过将输入直接映射到信道符号和任务输出，实现视觉语义传输，但其性能在训练域与部署域之间的分布偏移下可能下降。我们研究了面向任务型Deep JSCC的单源域自适应，并提出了一个分类-容量-不变性（CCI）函数，用以刻画可用信道容量和类条件跨域不变性如何影响目标域分类精度。对源域最优解的标量线性分析和受控浅层非线性验证表明，目标域分类精度可能随不变性约束以及通过改变传输维度或CSNR得到的独立控制路径上的可用容量呈非单调变化。然后，我们提出了一种域自适应Deep JSCC框架，该框架将基于伪标签的类级对抗对齐与对置信度过滤的目标样本进行监督对比学习相结合。在AWGN和瑞利衰落信道上对数字和PACS数据集的实验表明，在不引入额外推理时网络的情况下，目标域泛化性能得到了改进。在SVHN到MNIST的任务上，所提方法在CSNR为10 dB时实现了98.15%的目标域精度。

## Abstract
Deep joint source--channel coding (Deep JSCC) enables visual semantic transmission by mapping inputs directly to channel symbols and task outputs, but its performance can deteriorate under distribution shifts between training and deployment domains. We study single-source domain adaptation for task-oriented Deep JSCC and formulate a classification-capacity-invariance (CCI) function to characterize how the available channel capacity and class-conditional cross-domain invariance affect target domain classification accuracy. A scalar linear analysis of source-domain-optimal solutions and a controlled shallow nonlinear validation show that target domain classification accuracy can vary non-monotonically with the invariance constraint and with available capacity along separate control paths obtained by varying the transmitted dimension or CSNR. We then propose a domain-adaptive Deep JSCC framework that combines pseudo-label-based class-level adversarial alignment with supervised contrastive learning on confidence-filtered target samples. Experiments on digit and PACS datasets over AWGN and Rayleigh fading channels demonstrate improved target domain generalization without introducing additional inference-time networks. On SVHN $\rightarrow$ MNIST, the proposed method achieves 98.15\% target-domain accuracy at a CSNR of 10 dB.

## 2. 方法论

### 2.1 分类-容量-不变性（CCI）函数分析

**核心思想：** 定义CCI函数来刻画物理层配置η=(m,γ)（m为信道维度、γ为CSNR）和不变性预算M（允许的类条件跨域分布最大差异）对目标域分类风险的影响。

**数学框架：**
- 在给定η和M下，先最小化源域分类风险，约束为类条件分布距离≤M和功率约束，得到源域最优编码器/分类器，再评估其目标域风险：
  - FCCI(η,M) = Ct(θ*, φ*; η)
- 采用标量线性模型（二元高斯混合分布、类条件均值偏移），推导源域/目标域误差闭式解（式10、11）以及类间KL散度闭式解（式12）。
- 在AWGN和瑞利衰落信道上分别进行了标量线性分析，**关键发现：目标域精度既不随不变性约束单调变化，也不随信道容量单调变化**（图2、图3）。

### 2.2 受控非线性验证

- 采用单隐层MLP编码器和softmax分类器，K=5类、n=10维输入、one-hot类中心加高斯噪声构造源/目标域分布，用MMD作为类级分布距离。
- 沿“固定CSNR变m”和“固定m变CSNR”两条独立容量控制路径验证，结果与线性分析定性一致：目标域精度非单调（图4、图5），表明CCI关系在非线性编码和多类数据下依然成立。

### 2.3 提出的域自适应Deep JSCC框架

**整体结构：** 语义提取器 → 编码器 → 无线信道 → 解码器 → 分类器，全程训练端到端。

**核心技术1——类级域对齐（Class-level Domain Alignment）：**
- 构建K个二分类域判别器{Dk}，每个判别器只关注某一特定类别的源/目标域鉴别。
- 利用分类器输出的伪标签（ŷ = arg max p̂k，置信度q = max p̂k）对无标签目标样本进行类级分组。
- 每个判别器的对抗损失如式(21)：L_adv^(k) = -E[1[y=k]log(1-Dk(ẑs))] - E[1[ỹ=k]log(Dk(ẑt))]。
- 通过梯度反转层（GRL）实现编码器与判别器之间的max-min博弈，使同类别跨域特征分布不可区分。
- 相比全局对齐（如DANN），避免跨类塌缩和决策边界混淆。

**核心技术2——伪标签监督对比学习（Pseudo-label Contrastive Learning, PCL）：**
- 设置置信度阈值τ=0.8，过滤低置信度目标样本，得到参与对比学习的样本集合I（源域全部+目标域中qi>τ）。
- 采用带监督的多正样本InfoNCE损失（式25），以余弦相似度作为度量，拉近同（伪）类样本、推开异类样本。
- 该策略增强跨域类一致性，间接提高对信道噪声的鲁棒性。

**训练策略：**
- 两阶段训练：第一阶段仅用源域分类损失Lcls预训练10轮，生成可靠伪标签；第二阶段联合优化总损失 L = L_cls + λL_adv + βL_psup（λ=0.001, β=0.1），共60轮。
- 优化器为Adam，学习率0.0001，所有实验使用PyTorch实现。

## 6. 主要结论与发现

1. **CCI关系的非单调性：** 目标域分类精度不随跨域不变性增强而单调提升，也不随信道容量增加而单调提升；这一结论在标量线性模型和受控非线性模型中均成立，并分别在AWGN和瑞利衰落信道中得到验证。

2. **方法有效性：** 提出的类级对抗对齐+伪标签对比学习框架在数字和PACS数据集上均超越Deep JSCC、DANN JSCC、MDAN和KJDM，且推理时不需额外网络。
   - SVHN→MNIST：AWGN信道、CSNR=10 dB时目标域精度 **98.15%**（15 dB时为96.71%）；瑞利信道分别为82.34%和89.98%。
   - PACS（AWGN、CSNR=10 dB）：A→P 94.51%、A→C 82.51%、P→A 72.12%、P→C 68.13%、A→S 68.50%、P→S 53.23%，全部领先对比方法。

3. **消融验证：** 类级对齐和PCL均有独立贡献；两阶段训练稳定性优于单阶段；λ=0.001、τ=0.8为最优超参组合。

4. **复杂度优势：** 推理时与其他方法相同的计算/存储复杂度（58.51M FLOPs、0.55M参数、2.89 ms），而MDAN需要额外1.21G FLOPs、5.01M参数和7.71 ms。

## 7. 优点

- **理论深度：** 定义了CCI函数并给出线性闭式解分析，不是纯工程方法，而是从原理层面解释了“为什么不能一味追求强不变性或大容量”，为设计域自适应策略提供了理论指导。
- **类级对齐的思想创新：** 将传统DANN的粗粒度全局对齐细化为每个类别单独判别器，有效避免跨类塌缩，保留类判别信息。
- **伪标签+置信度过滤+两阶段训练的组合设计：** 充分考虑了无标签目标域数据利用中的可靠性问题，实现了质量与数量的平衡。
- **PCL损失的引入：** 在域自适应语义传输中首次将监督对比学习与伪标签结合，同时增强了跨域一致性和信道噪声鲁棒性。
- **零额外推理开销：** 判别器仅在训练时使用，推理时与普通Deep JSCC无异，对部署友好。
- **实验验证闭环：** 从理论分析到受控验证再到真实数据实验，逻辑链条完整，且用t-SNE和KL散度提供了表征层面证据。

## 8. 不足与局限

- **理论分析简化较多：** 线性分析仅考虑两类、高斯分布、标量编码器；非线性验证的类中心为双热向量构造，与现实数据的复杂语义结构差距较大。
- **单源域假设限制：** 仅支持一个源域+一个目标域的适应，不能直接扩展到多源域融合或持续学习场景。
- **伪标签依赖风险：** 在极端域偏移下（如P→S目标域精度仅53.23%），伪标签质量可能下降，两阶段训练虽缓解但无法彻底解决；置信度阈值需人为设定，且没有自适应调节机制。
- **信道模型受限：** 仅讨论AWGN和瑞利衰落，未考虑实际通信中更具挑战性的信道效应（如频率选择性衰落、硬件损伤、干扰）。
- **算力信息不透明：** 未报告训练所需的具体时间、能耗和内存占用，复现和部署规划有一定困难。
- **大模型/真实系统验证缺失：** 语义提取器最大规模仅为ResNet-18，未在大规模视觉Transformer或真实5G/6G协议栈上验证。
- **与现有方法的对比范围有限：** 虽对比了4种基线，但未与最新的生成式域自适应方法或端到端联合训练的新范式（如基于扩散模型的语义压缩）进行对比。
