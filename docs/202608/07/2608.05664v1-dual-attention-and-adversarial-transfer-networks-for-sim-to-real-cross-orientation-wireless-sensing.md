## 摘要
毫米波人体活动识别在用户相对于传感系统的方向发生变化时会出现显著的性能下降，然而收集带标签的多方向数据既费时又昂贵。为消除对大量多方向实测数据的需求，我们开发了一个物理引导的仿真器，可从单方向运动中合成方向多样化的无线训练数据。具体而言，为抑制方向引起的特征变化，我们提出了一种双注意力网络，从双链路多普勒频谱图中提取活动判别性强且方向鲁棒的表示。为弥合仿真到现实的差距，我们引入了一种对抗性无监督迁移学习机制，仅利用少量无标签目标域样本即可对齐特征分布。S2M-Sense平台在再现真实世界特征方面表现出高保真度，与60.48 GHz毫米波实测数据相比，在4种活动和4种方向下，仿真与实测多普勒频谱图之间的平均结构相似性指数（SSIM）为0.84。实验结果表明，仅使用双链路多方向仿真数据集，S2M-Sense即可达到88.33%的识别准确率；在仅使用16个无标签实测样本进行仿真到现实迁移学习后，准确率提升至95%。无论是否进行迁移学习，其性能均优于最先进的跨域感知方法。

## Abstract
Millimeter-wave human activity recognition suffers significant performance degradation when the user's orientation changes relative to the sensing system, yet collecting labeled multi-orientation data is labor-intensive and costly. To eliminate the need for exhaustive multi-orientation measured data, we develop a physics-guided simulator that synthesizes orientation-diverse wireless training data from single-orientation motion. Specifically, to suppress orientation-induced feature variations, we propose a dual-attention network that extracts activity-discriminative and orientation-robust representations from dual-link Doppler spectrograms. To bridge the simulation-to-reality gap, we introduce an adversarial unsupervised transfer learning mechanism that aligns feature distributions using only a small number of unlabeled target-domain samples. The S2M-Sense platform shows high fidelity in reproducing real-world signatures, validated against 60.48 GHz mmWave measured data with an average structural similarity index measure (SSIM) of 0.84 between simulated and measured Doppler spectrograms across all 4 activities and 4 orientations. Experimental results show that S2M-Sense achieves 88.33% recognition accuracy using only the dual-link multi-orientation simulated dataset, which improves to 95% after simulation-to-reality transfer learning with as few as 16 unlabeled measured samples. Both cases with and without transfer learning outperform state-of-the-art cross-domain sensing methods.

## 1. 核心问题与整体含义（研究动机和背景）

本文聚焦于**毫米波人体活动识别中的跨方向性能退化问题**：

- **背景**：基于Wi-Fi/毫米波信号的无设备人体活动识别在智能家居、健康监测等领域具有重要价值，相比摄像头方案更具隐私优势，相比可穿戴方案无需用户携带设备。
- **问题**：当用户相对于感知系统的朝向发生变化时，无线信号被显著扭曲，导致类内方差增大、识别性能急剧下降。已有的跨域感知方法（如WiAG、CrossSense、WiDual、WiGRUNT等）仍高度依赖实测的多朝向标注数据，而采集这些数据劳动密集、成本高昂。
- **核心目标**：**消除对大量多朝向实测数据的需求**——仅从单朝向动作采集出发，通过物理仿真合成多朝向训练数据，并用极少无标签实测样本完成域适应，实现跨方向活动识别。

## 2. 方法论

### 2.1 核心思想

提出**S2M-Sense**平台，包含四个组件：信道模拟器驱动的数据生成、实测多普勒频谱捕获、双注意力特征提取、仿真到现实对抗迁移学习。核心思路是"**仿真预训练 + 少量无标签域适应**"。

### 2.2 物理信道模拟器

- **人体建模**：深度相机（ZED 2i）30 fps采集动作视频，估计34个身体关键点，用椭球基元连接相邻关键点近似人体；经三次样条插值（提升至2000 fps）和One-Euro滤波平滑，改善时间连续性。
- **目标相关CIR**：每个椭球基元对双基地信道冲激响应（CIR）的贡献由式(2)建模，包含双基地RCS、收发天线增益（用ULA阵列因子建模）、距离损耗和相位项。
- **朝向扩展**：用绕腰部垂直轴的旋转矩阵 T(α)（式(5)）将关键点旋转到目标朝向，α为顺时针旋转角，y坐标不变。由此从单朝向采集生成全0°–360°多朝向仿真数据。
- **目标无关CIR**：由LOS路径（式(8)）和N个静态散射体NLOS路径（式(9)）组成。
- 最终由CIR经傅里叶分析生成多普勒频谱图，构造跨朝向仿真数据集。

### 2.3 双注意力网络

- 使用**两个近正交链路的双链路频谱图**作为输入，分别经ResNet-18提取特征 A1、A2，沿通道维拼接后经BN层归一化。
- **位置注意力模块（PAM）**：通过三个卷积生成特征图，矩阵乘法+softmax得到 N×N 空间注意力图，建模长距离空间依赖，突出运动相关区域、抑制背景噪声（式(10)(11)）。
- **通道注意力模块（CAM）**：通过特征展平、矩阵乘法和softmax生成 2C×2C 通道注意力图，建模通道间依赖，增强与活动相关的通道、抑制方向敏感通道（式(12)(13)）。
- **残差融合**：O = a·Op + b·Oc + A，a、b为可学习参数，初始化为0，使网络在训练初期保持原始特征并逐步增强注意力效果。

### 2.4 对抗无监督迁移学习

- 基于ADDA的对抗思路：先在仿真数据（源域）上预训练特征提取器 fs 和分类器；再用16个无标签实测样本作为目标域，交替优化：
  1. **优化判别器 D**：固定特征提取器，最小化式(16)的域判别损失；
  2. **优化目标特征提取器 ft**：固定D，最小化式(17)，使目标域特征逐渐与源域分布对齐。
- ft 初始化为 fs 的参数，迁移后可将训练好的分类器直接用于实测数据。

## 3. 实验设计

### 3.1 数据集与场景

- **感知系统**：60.48 GHz毫米波OFDM被动感知系统，发射端为NI USRP-2954R + Sivers相控阵天线，接收端两个同步相控阵天线构成两个**近正交链路**，用互模糊函数（CAF）得到双链路多普勒频谱图。
- **活动类别**：4种——step（踏步）、fall（跌倒）、sit（坐下）、kick（踢腿）。
- **仿真数据**：3名志愿者（A/B/C）、10个单朝向视频，随机采样0°–360°朝向，生成**3000个仿真频谱图**。
- **实测数据**：3名**不同**志愿者（D/E/F）、4个朝向（45°/135°/225°/315°），共**480个实测频谱图**。

### 3.2 Benchmark与对比方法

- 对比三种代表性跨域感知方法：**WiDual**、**WiGRUNT**、**ImgFi**。
- 为公平对比，所有baseline在**四种仿真数据集**上重新训练：（1）单朝向（SO）；（2）第一链路+多朝向（Link 1+MO）；（3）第二链路+多朝向（Link 2+MO）；（4）双链路+多朝向（Dual-link+MO），然后统一在实测测试集上评估。
- 另有**仿真-实测保真度验证**：计算各活动×各朝向组合下仿真与实测频谱图的SSIM。

## 7. 优点

- **方法层面亮点**：
  - 先物理建模仿真、后小样本域适应的范式，极大降低了对实测标注数据的依赖，实用性强；
  - 双链路近正交感知设计提供了更丰富的运动视角信息，显著提升方向鲁棒性；
