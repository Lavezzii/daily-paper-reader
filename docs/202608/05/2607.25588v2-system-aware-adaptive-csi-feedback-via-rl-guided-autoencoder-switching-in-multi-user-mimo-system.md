## 摘要
本文提出了一种用于大规模多输入多输出（mMIMO）系统的系统感知自适应信道状态信息（CSI）反馈框架，旨在动态优化重建保真度与信令开销之间的权衡。虽然基于深度学习自编码器（AE）已实现了显著的CSI压缩，但传统的固定比率方案无法有效适应非平稳信道条件。为解决这一局限性，我们开发了一种基于强化学习（RL）驱动的控制框架，该框架运行在一组预训练的多速率AE上，每个AE对应不同的压缩比（CR）。在每个时间步，集中式RL代理根据观测到的信道条件和系统性能指标为每个用户选择最合适的CR。与传统的基于均方误差（MSE）的设计不同，我们引入了一种系统感知的奖励公式，该公式通过信干噪比（SINR）联合考虑频谱效率、反馈开销约束以及模型自适应的计算成本。在高维延迟域CSI数据集上的仿真结果表明，所提出的RL引导框架能有效平衡开销-精度权衡，并适应动态信道环境。与固定压缩方案和自适应基线相比，所提方法在保持适度计算和内存开销的同时，提高了频谱效率和反馈效率。在不同用户数量和所有考虑基线的平均情况下，所提出的RL框架将CSI反馈成本降低了超过53.4%，平均下行链路和速率提高了53.64%，并将NMSE降低了22.38%。这些结果表明，它在动态无线条件下能够实现更有效的速率-精度-反馈权衡。

## Abstract
This paper proposes a system-aware adaptive channel state information (CSI) feedback framework for massive multiple-input multiple-output (mMIMO) systems, aiming to dynamically optimize the trade-off between reconstruction fidelity and signaling overhead. While deep learning-based autoencoders (AEs) have enabled significant CSI compression, conventional fixed-ratio schemes fail to adapt effectively to non-stationary channel conditions. To address this limitation, we develop a reinforcement learning (RL)-driven control framework that operates over a bank of pretrained multi-rate AEs, each corresponding to a distinct compression ratio (CR). At each time step, a centralized RL agent selects the most suitable CR for each user based on observed channel conditions and system performance indicators. Distinct from conventional mean squared error (MSE)-centric designs, we introduce a system-aware reward formulation that jointly accounts for spectral efficiency via signal-to-interference-plus-noise ratio (SINR), feedback overhead constraints, and the computational cost of model adaptation. Simulation results on high-dimensional delay-domain CSI datasets demonstrate that the proposed RL-guided framework effectively balances the overhead-accuracy tradeoff and adapts to dynamic channel environments. The proposed method improves spectral efficiency and feedback efficiency compared with fixed compression schemes and adaptive baselines, while maintaining a modest computational and memory footprint. Averaged over different numbers of users and across all considered baselines, the proposed RL framework reduces the CSI feedback cost by more than 53.4%, improves the average downlink sum rate by 53.64%, and reduces the NMSE by 22.38%. These results demonstrate its ability to achieve a more efficient rate-accuracy-feedback tradeoff under dynamic wireless conditions.

## 6. 主要结论与发现

- **自适应策略有效性**：RL 代理学会了按场景难度调节压缩比的策略——LoS 下以 0.94 的概率选 CR=1/32（重压缩），NLoS 下偏好 CR=1/16（概率 0.82），Blockage 下主选 CR=1/8（概率 0.93），说明策略具有清晰的场景感知能力。
- **系统性能提升**：跨 K={2,4,6,8} 平均，所提 RL 框架将 CSI 反馈成本降低超过 53.4%，平均下行和速率相对最佳固定基线提升 12.28%、相对 ATH 提升 9.24%、相对 LAD 提升 139.40%，NMSE 相比 ATH 降低 33.21%、相比最佳固定基线降低 21.97%、相比 LAD 降低 11.96%。相比固定 CR=1/4，反馈成本降低 55.5% 的同时和速率仍提升 5.66%。
- **适应性与鲁棒性**：在场景转换后，RL 框架比 ATH 和固定基线的性能下降更小、恢复更快，表明经验策略可以在无需在线重训练的情况下快速切换到合适的新 AE 配置。
- **可扩展性**：不同用户数（K=2 至 8）下均保持一致的收敛行为和相对优势，RL 决策延迟远小于 1 ms TTI 约束（约 50 μs），适合实际部署。

## 7. 优点与亮点

- **系统级奖励设计**：不以 NMSE 为唯一优化目标，而是将 SINR（吞吐）、NMSE（保真度）、反馈开销、切换成本融于一个奖励函数中，从“重建准确”走向“系统效率”，更加贴近实际部署需求。
- **“冻结 AE + 切换”范式**：不需要在线微调或梯度更新，避免了 UE 端反向传播/梯度存储开销，也规避了编码器-解码器失配问题——这是对现有自适应 CSI 反馈研究的一个重要补充。
- **低在线复杂度**：RL 在线推理仅需一次 MLP 前向传播（约 50 μs 决策延迟），模型参数少（约 40k），显著优于 LAD 等需要维护多套 AE 的分类自适应方法。
- **综合考虑多用户耦合**：通过系统级反馈预算惩罚将共享反馈约束纳入奖励，使 RL 代理能为多个用户协调分配资源，而非独立贪婪决策。
- **清晰的可复现性**：论文提供 GitHub 开源代码，AE 训练、数据生成与 RL 训练流程记录完整（如 Algorithm 1），表 I 对相关工作进行了全面的对比定位。

## 8. 不足与局限

- **缺少消融实验**：奖励函数中各项系数的贡献、状态空间中各特征的必要性均未做系统性消融，难以完全确定设计中每个组件的独立价值。
- **对比方案范围有限**：未与更现代的 RL 算法（如 PPO、软演员-评论家 SAC、多智能体 RL）或多速率 CSI 反馈方法（如嵌套 Dropout/VQ 方法）进行直接对比；ATH 规则与 LAD 基线在强非平稳场景下可能未充分调优，导致增益数值偏高（如与 LAD 的和速率差异高达 139%）。
- **数据与场景假设的理想化**：数据集基于 MATLAB 5G Toolbox 的 CDL 信道模型，所有用户经历同步全局场景切换（集体模式迁移），未包含异步用户切换、非理想信道估计、量化误差、反馈链路丢包与延迟等工程性问题。
- **扩展性有限**：用户数最大仅到 8，未验证更大规模（如 16、32 用户）下的 RL 收敛性和系统性能；系统级反馈预算的设定与惩罚权重的敏感性未分析。
- **训练算力信息缺失**：未报告 AE 预训练和 DQN 训练的具体硬件与时长，读者难以评估整体训练成本。
- **AE 架构较为基础**：全连接 AE 在捕获高维空间-频率相关性上不如 CNN/Transformer，而更高效的主干网络是否影响 RL 切换策略的收益，论文未讨论。
- **无真实硬件验证**：全流程延迟 250 ms 是在软件仿真环境测得，缺少原型系统（如 SDR 平台）上的端到端实证验证。
