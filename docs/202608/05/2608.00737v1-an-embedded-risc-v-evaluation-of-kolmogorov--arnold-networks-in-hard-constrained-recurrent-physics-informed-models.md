## 摘要
硬约束循环物理信息网络（HRPINN）将已知动力学嵌入循环数值积分器中，并将神经分支限制为仅学习第一性原理模型未捕捉到的残差动力学。Kolmogorov-Arnold网络（KAN）已被提出作为此类残差分支中多层感知机（MLP）的参数高效替代方案，但其可学习的B样条激活函数遵循显著不同的执行特征。基于先前的工作（该工作描述了在发现准确性方面，普通B样条KAN在作为HRPINN残差分支时何时匹配或不如MLP），本文探讨这种参数效率在部署中是否仍然存在。使用相同的训练权重，我们在无向量扩展的RISC-V RV64GC平台（StarFive VisionFive~2, SiFive U74）上，在闭环循环中测量了执行延迟、每积分步能量以及训练后量化下的可靠性。对于两个精度可比较的配对，KAN残差分支执行速度慢13.5倍和8.0倍，每个积分步消耗能量多11.3倍和5.6倍（最小配对为3.7 μJ对0.33 μJ）；在所有四个参数匹配的尺寸层级中，范围分别为4.7倍至14.5倍和4.7倍至18.7倍。在INT8量化下，KAN轨迹的发散时间比匹配的MLP提前达43倍；损伤归因于权重量化，而非输入侧节点区间错误分配。这些结果表明，KAN报告的参数效率并未转化为标量嵌入式核心上的部署成本优势，并且除非采用特定的量化协同设计，否则MLP残差分支是嵌入式HRPINN部署中更可靠的默认选择。

## Abstract
Hard-constrained recurrent physics-informed networks (HRPINNs) embed known dynamics inside a recurrent numerical integrator and restrict a neural branch to learning only the residual dynamics that the first-principles model does not capture. Kolmogorov--Arnold Networks (KANs) have been proposed as parameter-efficient replacements for multilayer perceptrons (MLPs) in such residual branches, but their learnable B-spline activations follow a markedly different execution profile. Building on prior work that characterized when a vanilla B-spline KAN matches or underperforms an MLP as an HRPINN residual branch in discovery accuracy, this paper asks whether that parameter efficiency survives deployment. Using identical trained weights, we measured execution latency, energy per integration step, and dependability under post-training quantization in the closed recurrent loop on a RISC-V RV64GC platform without vector extensions (StarFive VisionFive~2, SiFive U74). For the two accuracy-comparable pairs, the KAN residual branch executed $13.5\times$ and $8.0\times$ slower and consumed $11.3\times$ and $5.6\times$ more energy per integration step (3.7\,$μ$J against 0.33\,$μ$J for the smallest pair); across all four parameter-matched size tiers the ranges are $4.7\times$--$14.5\times$ and $4.7\times$--$18.7\times$. Under INT8 quantization, KAN trajectories diverged up to $43\times$ earlier than matched MLPs; the damage traces to weight quantization, not to input-side knot-interval misassignment. These results indicate that the parameter efficiency reported for KANs does not transfer to deployment cost on scalar embedded cores, and that an MLP residual branch is the more dependable default for embedded HRPINN deployment unless specific quantization co-design is used.

## 2. 方法论：核心思想、关键技术细节与算法流程

**（1）HRPINN 基本结构**
- 状态向量为 sₜ = [xₜ, vₜ]ᵀ ∈ R²，采用显式欧拉步进：ẋₜ = vₜ，v̇ₜ = a_known(sₜ) + R_θ(sₜ)，其中 a_known 是已知动力学项，R_θ 是待学习的残差分支。
- 仅残差分支 R_θ 参与训练（通过 20 步窗口的 BPTT），积分器与已知动力学项固定不变，因此架构对比等价于残差分支的对比。

**（2）KAN 的数学形式**
- 单层 KAN 将 MLP 的标量激活替换为每个边上的可学习单变量函数：ϕ(x) = w_b·SiLU(x) + w_s·Σ_j c_j B_j(x)，其中 B_j 是 B 样条基函数，c_j 是学习系数。
- 默认配置：网格大小 G=5、样条阶数 k=3，训练中应用网格更新，故最终结点向量是非均匀且随模型而异的。

**（3）嵌入式推理框架**
- 训练在 x86-64 主机上离线完成（PyTorch），部署时导出为紧凑二进制文件（仅 C++17 标准库 + libm，静态链接）。
- 推理引擎无动态分配，MLP 为融合的矩阵向量乘 + ReLU；KAN 为 SiLU 基路径（含 expf 调用）+ Cox-de Boor 样条递归 + 样条矩阵向量乘。
- 提供两种 KAN 核实现：默认版（逐操作复现 PyTorch 数值）和优化版（预计算结点差分的倒数），后者量化了实现优化对差距的影响。

**（4）量化方法**
- 采用与架构无关的标准训练后静态量化：对称按张量权重量化 + 仿射按张量激活/状态量化，精度包括 INT16、INT8、INT6、INT4。
- 特别包含 5 种量化模式以便归因分析：full（端到端整数循环）、residual_only（仅分支量化）、input-only、weights-only、activations-only。

## 6. 主要结论与发现

**H1（延迟）成立**：
- 精度可比的配对：KAN Very Small 比 MLP Tiny 慢 13.5×（11.1 μs vs 0.83 μs）；KAN Small 比 MLP Small 慢 8.0×。
- 全部四档：4.7×–14.5×；归一化到每参数，KAN 为 41–93 ns/参数（均值 73），MLP 为 6.2–8.0 ns/参数（均值 6.9）——与参数计数所暗示的正好相反。
- 预计算倒数优化仅恢复 6–18% 延迟，不改变趋势。

**H2（能耗）成立**：
- 精度可比配对：能耗高 11.3× 和 5.6×（最小配对 3.7 μJ vs 0.33 μJ）；全部四档 4.7×–18.7×。
- 能量惩罚等于而非超过延迟惩罚（固定频率恒功率），能量-延迟比值均值为 1.01（散布 0.70–1.46，在测量误差带内）。

**H3（量化可靠性）成立**：
- INT16 下所有模型均可在 100 秒内保持阈值内（除先前已标记为不稳定的 KAN 配置）。
- INT8 full 模式下所有模型最终发散（8-bit 状态分辨率 2/255 的累积效应），但发散时点差异显著：Duffing 上 KAN Very Small 中位第 6.5 步发散，MLP Tiny 第 282 步，差距达 43×。
- 归因分析：输入侧结点区间错分配几乎无害（输入量化步长 ≈0.008，远小于网格间隔 0.4）；权重量化才是损伤主因（weights-only 已复现 KAN 大部分退化），与 MLP 的权重分布相比，KAN 的样条系数张量各边异质性更强，单一按张量尺度压缩不成比例地损害小系数。

**总体结论**：
- KAN 的参数效率未转化为嵌入式标量核上的部署成本优势；经典核优化（查表替换 expf、预计算倒数）加上去最多收回约 1/4 差距。
- 无协同设计时，MLP 残差分支是嵌入式 HRPINN 更可靠、更省资源的默认选择；KAN 仅在内存占用为硬约束、残差可加可分离且执行精度维持 FP32/INT16 时才值得考虑。

## 7. 优点：方法与实验设计的亮点

- **公平的对比设计**：使用相同训练权重、相同编译器/标志、相同测量工具链；部署取中位数种子而非最优种子，避免乐观偏差；集成器固定不变使架构对比纯粹落在残差分支上。
- **多方位的验证链条**：FP32 路径与 PyTorch 在 10⁻⁴ 内吻合、MLP 路径与 NumPy 参考逐位一致、量化路径与独立 Python 实现钉在 1 个量化步内，qemu 与实机整数路径逐位一致，确保测量可信度。
- **归因分析设计精巧**：通过 5 种量化模式将损伤定位到权重量化本身而非 KAN 特有的输入区间错分配机制，排除了“无密集层对应”的混淆因素，为后续协同设计指明方向（逐边或逐通道样条权重尺度）。
- **工程严谨性**：固定 CPU 频率 governor 消除变频干扰；差分能量测量扣除空闲功率；校验和防止编译器消除计算；CPU 频率与能耗在同一工作点测量。
- **可复现性**：推理引擎、训练模型、测量脚本全部公开，部署仅需两个文件。

## 8. 不足与局限

- **实验覆盖窄**：仅两个二阶、两状态、自治、无外力、无间断/迟滞动力学系统；未覆盖更高维度、刚性系统（需隐式积分）、多速率行为等实际 CPS 场景。论文承认其结论的方向性外推需针对具体系统重新验证。
- **硬件代表性有限**：仅评估一个标量核（无向量扩展）；向量核会改变两者的常量，且 KAN 的分支密集、gather-heavy 递归比稠密矩阵乘更难向量化，这一推断未经验证。
- **量化评估为模拟而非真实部署**：量化路径是数值模拟（模拟整数语义 + 张量边界反量化），虽然精确复现数值效果，但不具备真实整数流水线的延迟/能耗；论文明确声明不据此作整数执行速度与能耗的结论。
- **能耗测量精度受限**：库仑计 1 mAh 分辨率（对应 153 mW @5.11V）导致每模型能耗约 ±19% 误差，且无法区分两种架构增量功率的差异低于 153 mW 的部分；更细粒度归因需核供电轨级别的仪器。
- **恒功率假设的条件性**：能量 ≈ 延迟 × 恒定功率的结论在固定频率 governor 下成立；若采用按需变频 governor，长时运行会推高工作点，能耗惩罚可能超过延迟惩罚。
- **训练资源细节缺失**：未报告 GPU 型号、数量与训练时长，无法评估训练侧的成本差异。
