## 摘要
我们提出RSTA，一种域泛化的语义通信框架，能够在观测域偏移和未见无线信道条件下实现无源的V2X协同感知。在V2X中，接收到的语义标记遭受传输前域漂移和传输中信道损坏的耦合退化；现有方法仅处理单一来源，导致适应过程被同时偏离域和物理退化的标记误导。RSTA通过跨域原型对齐和跨信道梯度一致性训练部署前的语义编码器以实现传输稳定性，并通过基于可靠性门控的熵最小化更新部署中的轻量级解码器适配器，该最小化将梯度限制在语义相关性和信道保真度均排名较高的标记上。理论的任务鲁棒性分解将每个损失项与不同的退化来源相关联，使每个算法组件都对应可测量的错误模式。在AWGN上训练并在未见过的瑞利衰落上测试，RSTA在跨天气任务上相对部署前域泛化实现了+7.2 AP@0.7的提升，在跨数据集任务上实现了+5.5的提升，涉及四个V2X基准，部署中仅更新0.21%的参数，且代理间同步开销为零。

## Abstract
We propose RSTA, a domain-generalized semantic communication framework enabling source-free V2X collaborative perception under both observation-domain shift and unseen wireless channel conditions. In V2X, received semantic tokens suffer coupled degradation from pre-transmission domain drift and in-transit channel corruption; existing methods address only one source, leaving adaptation misled by tokens that are simultaneously off-domain and physically degraded. RSTA trains a pre-deployment semantic encoder for transmission stability via cross-domain prototype alignment and cross-channel gradient consistency, and updates a lightweight in-deployment decoder adapter through reliability-gated entropy minimization that restricts gradients to tokens ranked high in both semantic relevance and channel fidelity. A theoretical task robustness decomposition links each loss term to a distinct degradation source, grounding each algorithmic component in a measurable error mode. Trained on AWGN and tested on unseen Rayleigh fading, RSTA achieves +7.2 AP@0.7 over pre-deployment domain generalization on cross-weather tasks and +5.5 on cross-dataset tasks across four V2X benchmarks, updating only 0.21\% of parameters in-deployment with zero inter-agent synchronization overhead.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：面向任务的语义通信（task-oriented semantic communication）在 V2X 协同感知中具有重要意义。多个车辆通过无线链路交换压缩后的 BEV（Bird's Eye View）语义特征，以弥补视距遮挡和感知范围限制。
- **核心问题**：部署环境中存在**双重耦合的分布偏移**：
  - **观测侧偏移（Observation-domain shift）**：天气、场景布局、数据集变化导致编码前的特征分布发生改变；
  - **传输侧偏移（Transmission-side shift）**：动态信噪比、衰落等无线信道损伤在传输过程中扰动编码特征。
  - 由于接收端只能看到经过信道后的令牌（token），域偏移和信道损坏在**同一接收特征中相互纠缠**，而现有方法大多只处理其中一个来源：
    - 域泛化（Domain Generalization）方法忽略信道畸变；
    - 测试时适应（TTA）方法假设干净输入，无法处理通信损坏的令牌；
    - 语义通信方法多面向单用户分类或需要标注目标数据。
- **核心动机**：需要一种同时处理观测偏移、信道偏移、且支持无源（source-free）部署适应的任务导向语义通信方法。

## 2. 论文提出的方法论

### 2.1 核心思想

论文提出 **RSTA**（Reliability-gated Source-free Test-time Adaptation）框架，包含两个阶段：

- **预部署训练阶段**：学习对跨域和跨信道均稳定的语义编码；
- **部署适应阶段**：仅通过可靠性门控的熵最小化更新轻量级接收端适配器。

### 2.2 系统模型

- 每个协作者的局部观测经骨干网络提取 BEV 特征，经语义选择器保留 top-U 关键令牌，编码为紧凑码字张量。
- 经无线信道传输，接收端收到含信道系数和噪声的退化码字。
- 接收端使用语义解码器+适配器恢复特征，经空间融合模块进行 3D 检测。

### 2.3 预部署训练（Pre-Deployment Transmission-Stable Semantic Learning）

包含四个正则化损失项：

- **跨域原型对齐（Lproto）**：将各源域的解码特征原型与全源域均值原型对齐，减小语义漂移；
- **跨信道梯度一致性（Lch）**：基于 Fishr 原理，匹配不同训练信道的梯度协方差对角项，防止特征过度特化到某一信道；
- **码能量紧凑性（Lcmp）**：降低码字能量，作为发射功率代理并减小信道敏感性；
- **不确定性头训练（Lunc）**：预测令牌在两次随机信道采样下的预测分歧（KL 散度），为部署时的可靠性评分提供依据。

总损失：`L_off = L_det + λp·Lproto + λc·Lch + λn·Lcmp + λu·Lunc`

### 2.4 部署阶段（Reliability-Gated Receiver Adaptation）

- **可靠性评分**：`r_u = sigmoid(w1·a_u + w2·ρ_u − w3·σ̂_u)`，其中 a_u 是发送端语义重要性，ρ_u 是接收端信道置信度（基于接收信号幅度），σ̂_u 是预测不确定性。三项加权（权重在预部署时联合学习），综合衡量令牌的语义相关性和物理可信度。
- **可靠性门控熵最小化（Lent）**：按可靠性分数加权熵损失，使不可靠令牌不主导梯度。
- **软原型锚定（Lspa）**：使目标特征原型不偏离源域语义流形。
- **仅更新适配器参数 ψ**，更新限制在源检查点附近（L2 正则化）。

### 2.5 理论分析（任务鲁棒性分解）

通过 Lipschitz 假设，将目标域检测风险分解为四项：

1. **语义原型漂移**（对应 Lspa）；
2. **信道敏感性**（对应 Lcmp，减小码能量以收紧误码上界）；
3. **不可靠令牌质量**（对应 Lch 和 Lunc，门控抑制其影响）；
4. **可靠令牌熵**（对应 Lent）。

论文指出：普通熵最小化只减少最后一项，且对所有令牌一视同仁，因此在联合偏移下表现较弱。

### 2.6 算法流程

部署时对每个无标注目标批次：接收并解码 → 计算后验与可靠性分数 → 由（14）（15）形成熵损失和原型对齐损失 → 仅更新适配器参数（1-2 步 Adam 步）→ 使用适应后的模型推理。

## 6. 主要结论与发现

- **RSTA 在联合观测-传输偏移下显著优于现有方法**：
  - 天气偏移 + Rayleigh 信道，12 dB 下达到 61.7 AP@0.7，较预部署 DG **+7.2**；

- **理论分解与算法设计闭环**：每个损失项都对应于可测量的误差模式。
