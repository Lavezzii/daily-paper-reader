## 摘要
利用分布式多输入多输出（D-MIMO）和机器学习（ML）的室内定位可实现亚厘米级精度，但在开放无线接入网（O-RAN）架构中传输原始信道状态信息（CSI）时会面临中传容量瓶颈。为解决此问题，我们提出一种轻量级分布式ML框架，将初始处理移至网络边缘。通过在分布式单元（DU）上部署本地化模型作为分布式应用（dApps），每个模型仅需1.39 MB内存和1.96 MFLOPs，系统可在边缘执行CSI特征提取与缩减。缩减后的低维特征被传输至中央单元（CU），其上部署另一dApp进行位置估计。基于高密度数据集的评估表明，即使仅部署一半的射频单元（RU），该框架也能将中传流量降低100倍，同时保持8.5毫米的平均误差，为实际D-MIMO定位提供了可扩展的蓝图。

## Abstract
Indoor localization using Distributed Multiple-Input Multiple-Output (D-MIMO) and machine learning (ML) achieves sub-centimeter accuracy but faces midhaul capacity bottlenecks when transmitting raw Channel State Information (CSI) in Open Radio Access Networks (O-RAN) architectures. To address this, we propose a lightweight, distributed ML framework that shifts initial processing to the network edge. By deploying localized models as dApps on Distributed Units (DUs), each requiring just 1.39 MB of memory and 1.96 MFLOPs, the system performs CSI feature extraction and reduction on the edge. The reduced low-dimensional features are transmitted to the Central Unit (CU), where another dApp is deployed for location estimation. Evaluated on a high-density dataset, this framework reduces midhaul traffic by 100x while maintaining an average error of 8.5 mm, even with half the deployed Radio Units (RUs), providing a scalable blueprint for practical D-MIMO localization.
