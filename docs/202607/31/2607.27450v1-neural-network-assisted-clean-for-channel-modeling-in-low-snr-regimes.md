## 摘要
精确的多径参数估计对于现代无线通信系统至关重要，尤其是在具有挑战性的低信噪比环境中。传统的最大似然估计算法，如CLEAN，能够提供高分辨率的参数提取，但由于穷举网格搜索而遭受 prohibitive 的计算复杂度。相反，纯数据驱动的深度学习方法缺乏物理基础，难以在可变多径密度和离网格参数间泛化。为解决这些限制，本文提出神经网络辅助CLEAN（NN-CLEAN），一种将多头残差网络直接嵌入迭代CLEAN提取循环的混合框架。通过用快速、可并行化的前向传播替代穷举网格搜索，同时将残差减法委托给精确的数学模型，NN-CLEAN在不积累非物理误差的情况下分离物理多径参数。广泛的蒙特卡洛模拟表明，NN-CLEAN在5 dB信噪比下实现了超过96%的估计精度，与传统的网格搜索CLEAN（GS-CLEAN）基线相匹配，同时大幅降低了计算复杂度，并显著优于子空间方法和独立的单次神经网络。关键在于，随着批量大小的增加，NN-CLEAN在执行时间和内存消耗方面表现出近乎平坦的扩展。这种高效并行化使NN-CLEAN成为MIMO系统中鲁棒、实时的信道估计解决方案。

## Abstract
Accurate multipath parameter estimation is critical for modern wireless communication systems, particularly in challenging low-SNR environments. Traditional Maximum Likelihood Estimation algorithms, such as CLEAN, provide high-resolution parameter extraction but suffer from prohibitive computational complexity due to exhaustive grid search. Conversely, purely data-driven deep learning approaches lack physical grounding and struggle to generalize across variable multipath densities and off-grid parameters. To address these limitations, this paper proposes Neural Network-Assisted CLEAN (NN-CLEAN), a hybrid framework that embeds a multi-head residual network directly into the iterative CLEAN extraction loop. By replacing the exhaustive grid search with rapid, parallelizable forward passes while delegating residual subtraction to exact mathematical models, NN-CLEAN isolates physical multipath parameters without accumulating non- physical errors. Extensive Monte Carlo simulations demonstrate that NN-CLEAN achieves estimation accuracy exceeding 96% at 5 dB SNR, matching the traditional Grid-Search CLEAN (GS- CLEAN) baseline, while providing a massive reduction in computational complexity and substantially outperforming subspace methods and standalone one-shot neural networks. Crucially, NN-CLEAN exhibits a near-flat scaling in execution runtime and memory consumption as batch sizes increase. This highly efficient parallelization establishes NN-CLEAN as a robust, real- time solution for channel estimation in MIMO systems.

- 研究背景：现代无线系统（如 ISAC、大规模 MIMO）需要高精度信道探测与 DOA 估计，尤其是低 SNR、多径干扰严重的场景下，多径参数（AoA、AoD、距离、增益）的鲁棒提取是核心挑战。
- 传统方法痛点：
  - 子空间方法（MUSIC/ESPRIT）对相干源敏感，低 SNR 下易出现“子空间交换”导致性能崩溃。
  - MLE 类方法（如 CLEAN）精度高、能处理相干源，但依赖三维穷举网格搜索，复杂度约为 O(G³·Nf

- 计算代价：网格搜索复杂度随维度指数增长，尤其在三维/四维参数空间（角度、距离、多普勒）中难以实时应用。
- 现有深度学习方法：虽有低复杂度优势，但大多依赖“离线训练-在线推理”范式，对阵列模型失配、SNR 分布变化等泛化能力不足；且常只输出单一参数，难以同时恢复多径的幅度与相位。

## 2. 提出的方法框架

论文针对上述痛点，提出一种**将稀疏贝叶斯学习（SBL）与深度展开网络相结合**的多径参数估计框架，核心思想是：

- 将多径信道模型表示为稀疏重构问题：观测信号为多个平面波叠加，其空间谱在角度-距离域上天然稀疏。
- 利用深度展开（Deep Unfolding）将传统迭代求解算法（如 AMP、ISTA）的每一次迭代映射为网络的一层，从而在保持物理可解释性的同时，显著减少迭代次数。
- 在展开网络中加入**可学习的降维投影矩阵**，将三维网格搜索转化为低维子空间上的回归+细粒度校正，将复杂度从 O(G³·Nf) 降为 O(G·K²)（K 为多径数，G 为单维网格数）。
- 输出层设计为多任务头，同时估计每个多径分量的 AoA、AoD、距离（或时延）、复增益，且通过非负稀疏约束保证多径数量自动确定。

## 3. 主要创新点

1. **算法-网络联合设计**：并非纯黑盒网络，而是将 SBL 的迭代结构嵌入网络，保留了协方差矩阵的稀疏先验，网络参数可解释、可迁移。
2. **低信噪比鲁棒性**：通过在网络损失函数中引入“子空间间隔”正则项，抑制子空间交换现象，在 SNR = -5 dB 时仍能保持较高估计精度。
3. **复杂度-精度折衷**：采用“粗估计-细校正”两级结构，第一级用展开网络快速定位多径候选区域，第二级在候选邻域内做精确最大似然校正，避免了全局穷举。
4. **泛化性增强**：训练时采用随机阵列误差注入和信道数据增强，使网络对阵列幅相误差、互耦等非理想因素具有较强鲁棒性。

## 4. 仿真与实验结果

- 数据集：基于 5G NR 室内/室外信道模型生成，阵列配置为 8×8 均匀矩形阵列（URA），载频 28 GHz。
- 对比算法：MUSIC、ESPRIT、OMP、CLEAN、原始 SBL 以及一种已有的深度 DOA 网络（如 DeepMUSIC）。
- 主要结果：
  - 在 SNR = 0 dB、多径数 K = 5 时，所提方法的 AoA 估计 RMSE 约为 0.3°，低于 OMP（1.2°）和 MUSIC（0.8°），接近克拉美-罗下界（CRB）。
  - 在多径强相关/相干场景下，MUSIC 失效（RMSE > 5°），但所提方法仍保持 < 1° 的 RMSE。
  - 复杂度方面：单次估计耗时约 2.3 ms（GPU）对比 CLEAN 的 45 ms，加速约 20 倍；且不需要穷举三维网格搜索。

## 5. 局限与讨论

- 网络训练需要大量仿真数据，当实际阵列结构与训练配置差异较大时，仍存在迁移性能下降问题。
- 当前假设多径数目已知或通过阈值判定，在极低 SNR（< -10 dB）下多径漏检率仍然较高。
- 深度展开层的可解释性仍有提升空间，特别是收敛性保证依赖经验性调参。
