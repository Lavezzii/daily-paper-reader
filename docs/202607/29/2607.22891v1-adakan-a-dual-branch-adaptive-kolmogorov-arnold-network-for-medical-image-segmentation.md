## 摘要
医学图像分割是计算机辅助诊断中的一项基本任务，但由于解剖结构的复杂性和成像模态的多样性，它仍然具有挑战性。在本文中，我们提出了AdaKAN，一种自适应Kolmogorov-Arnold网络（KAN），它协同地将卷积操作与一种新颖的高效KAN（EffiKAN）模块相结合，该模块由高效注意力机制和自适应KAN（AdaptKAN）模块组成。该模块采用双分支设计：一个分支使用具有Bernstein多项式激活函数的KAN层，用于全局平滑且稳定的函数逼近，而另一个分支通过投影操作和自适应缩放执行通道级细化。AdaKAN采用U形架构，有效捕获长距离依赖和细粒度局部特征，克服了传统卷积和基于Transformer的分割模型的局限性。跳跃连接用于在编码过程中保留空间细节，并在解码过程中促进准确重建。在多种医学成像数据集上进行的大量实验表明，AdaKAN在分割精度上达到了最先进的性能。

## Abstract
Medical image segmentation is a fundamental task in computer-aided diagnosis, yet it remains challenging due to the complexity of anatomical structures and the variability across imaging modalities. In this paper, we propose AdaKAN, an Adaptive Kolmogorov-Arnold Network (KAN) that synergistically integrates convolutional operations with a novel efficient KAN (EffiKAN) block, comprised of an efficient attention mechanism and an adaptive KAN (AdaptKAN) module. This module features a dual-branch design: one branch employs a KAN layer with Bernstein polynomial activations for globally smooth and stable function approximation, while the other branch performs channel-wise refinement through projection operations and adaptive scaling. AdaKAN adopts a U-shaped architecture that effectively captures both long-range dependencies and fine-grained local features, overcoming the limitations of conventional convolutional and Transformer-based segmentation models. Skip connections are employed to preserve spatial details during encoding and facilitate accurate reconstruction during decoding. Extensive experiments conducted on diverse medical imaging datasets demonstrate that AdaKAN achieves state-of-the-art performance in segmentation accuracy.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：医学图像分割是计算机辅助诊断的基础任务，但面临解剖结构复杂、成像模态多样等挑战。
- **现有方法局限**：
  - 全卷积网络（FCN）由于卷积的局部性无法捕获长程依赖，导致边界模糊或分割不完整。
  - Transformer 类方法（如 TransUNet）能捕获全局上下文，但计算复杂度为二次（O(n²)），在资源受限场景不实用。
  - MLP 类方法（如 UNeXt）计算高效，但表达能力有限，难以建模复杂结构。
  - 近年提出的 Kolmogorov-Arnold Network（KAN）将可学习参数从节点函数移至边上的单变量激活函数，具有更好的可解释性和非线性建模能力；但现有 KAN 类方法（如 U-KAN）仍使用 B-spline 激活，全局上下文建模能力不足。
- **本文目标**：设计一个平衡局部精度、全局感知和计算效率的框架，用于多种医学影像分割任务。

## 2. 方法论：核心思想、关键技术细节

- **整体架构**：对称的 U 形编码器‑解码器，包含：
  - **卷积阶段**：3 个卷积块（Conv+BN+ReLU），逐步下采样提取多尺度低级语义特征。
  - **EffiKAN 阶段**：由多个 EffiKAN 块组成，每个块依次包含 Patch Embedding、LayerNorm、高效注意力（Efficient Attention）和 AdaptKAN 模块，并带有残差连接。
- **关键技术**：
  1. **高效注意力**：计算复杂度从 O(n²) 降至 O(n)。使用行/列 Softmax 分解：EA(LN(Y)) = σ_row(Q) × (σ_col(K)ᵀ V)。保留了每个 token 聚合所有 token 信息的能力。
  2. **AdaptKAN 模块**（双分支设计）：
     - **左分支**：KAN 层，激活函数为 Bernstein 多项式基函数：ϕ̃(z) = w̃_b SiLU(z) + w̃_s Bern(z)，Bern(z) = Σ θ_r * C(R, r) * z^r * (1-z)^{R-r}。实现全局平滑且稳定的函数逼近。
     - **右分支**：轻量瓶颈结构（Down‑Projection → ReLU → Up‑Projection），进行通道级细化，并由可学习缩放系数 s 控制贡献，初始化为小值（如 0.1）以稳定训练。
     - 输出 = KAN(LN(Z)) + s · Z̃。
  3. **解码器**：镜像对称，使用双线性插值上采样+跳跃连接恢复空间细节；最后经 1×1 卷积和 Softmax 输出像素级分类。
- **数学流程**（文字说明）：输入图像 I → 3个卷积块下采样到 H/8×W/8×C3 → Patch Embedding 得到令牌序列 Y → LayerNorm → 高效注意力（残差加 Y 得 Z）→ AdaptKAN（KAN分支+缩放瓶颈分支，残差加 Z）→ 重复两次 EffiKAN 块 → 解码器上采样+跳跃连接 → 最终分割掩模。
